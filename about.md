# Bot Auto Play

An auto-play bot mod for Geometry Dash that helps automate gameplay.

## How it works
The bot monitors the game state and automatically performs actions based on obstacle detection.

## Settings
- **Enable Bot**: Turn the bot on or off
- **Play Speed**: Control how fast the bot plays (0.5x to 2.0x speed)

## Development
This mod is built using the Geode SDK for iOS.

For more information, visit the repository.
